- **Date:** 2026-11-26
- **Site:** Tools Websites Directory — https://tools-websites-directory.pages.dev
- **Scope:** Research only. No files edited, nothing deployed, no money spent.
- **Method:** Public web search (Semrush, Similarweb, Keywords Everywhere, HypeStat, Statvoo, Sitelike, listicle/ranking pages). All traffic and volume figures below are **third-party estimates, not measured data** — Semrush/Similarweb numbers for the same domain routinely disagree by 2–5× (e.g. calculator.net: Semrush 77.3M visits Oct 2026 vs Similarweb ~40M). Use them for *relative* ranking and keyword discovery, never as exact volumes.
- **Site routes (verified from `frontend/src/App.jsx`):** `/` (Home), `/sites`, `/tiers/:tier` (a–f), `/top-10`, `/gaps`, `/categories`, `/about`, `/sources`, `/search`.

## 1. The site's real search position (read this first)

This site is a **directory/review site**: it lists and reviews 78 tools websites in Tiers A–F. It does **not** calculate anything. That single fact decides the whole keyword strategy:

- **It can honestly win:** directory / comparison / "best … websites" queries, brand + "alternative" queries, and Pakistan-specific *list* queries ("best calculator website in Pakistan", "FBR tax calculator — which site is best").
- **It cannot honestly win:** the bare tool query itself ("BMI calculator", "mortgage calculator", "percentage calculator"). Google answers those with an interactive calculator or the tool page itself, not a directory. Targeting them head-on is a mismatch of search intent and will not rank — no matter how good the on-page SEO is.
- **The 1-month, first-page goal is only realistic for low-competition, directory-intent and Pakistan long-tail queries.** "Calculator" itself is unwinnable in a month (see §5).

## 5. (d) Prioritised quick-win order (1-month goal)

Ranking logic: low competition + exact intent match + a page that already exists and honestly answers = first. Bare tool keywords are unwinnable in a month and are listed last as "do not chase".

### Week 1 — ship these first (highest probability of page 1)

1. **Pakistan cluster on `/tiers/d`** — phrases #1, #2, #4, #6, #8, #12, #14, #22 from §4 + keywords #17, #18, #20, #21, #30, #31, #32 from §3. *Why first:* zero directory competition, all queries are list/comparison intent, one page carries the whole cluster via FAQs. This is the single best bet for page 1 in a month.
2. **"best calculator websites" on `/top-10`** — keyword #1 (+ #2, #3, #10, #28). *Why:* the direct head term for the site's purpose; current top-10 pages are thin, stale listicles (GeeksMint is from 2020). A reviewed, tiered top 10 with a comparison table can outrank them.
3. **"calculator.net alternatives" + "vs" FAQs on `/top-10`** — keywords #8, #9, #26, #27. *Why:* near-zero competition for the exact question; Miryori's alternatives page is the only strong rival and it discloses a self-listing.

### Week 2 — second wave

4. **Tier E Islamic cluster on `/tiers/e`** — keywords #19, #23 + phrases #8, #9, #24. *Why:* tiny niche (3 sites), no competing directory page at all.
5. **Tier F farmer cluster on `/tiers/f`** — keywords #24 + phrase #25. *Why:* same logic; smallest tier, least competition.
6. **Homepage directory terms** — keywords #5, #6, #7 + phrase #26 on `/`. *Why:* broader, slower; homepage authority builds last.
7. **Category-intent "best [X] calculator website" on `/categories`** — keywords #13–#16, #25. *Why:* winnable long tail, but each needs a genuine category section naming the best site for that job; slower than the Pakistan cluster because global listicles also answer some of these.

### Week 3–4 — consolidation

8. **`/gaps` for gap-intent queries** — keyword #29. *Why:* unique page, but search volume for gap phrasing is tiny; it supports the site's authority more than it drives traffic.
9. **`/sites` list terms** — keywords #4, #11, #12. *Why:* supporting pages; "calculator websites list" is low-volume but exact-fit.

### DO NOT CHASE in month 1 (too competitive / intent mismatch)

- **"calculator"** — 24.9M/mo, calculator.net sits #2 with 77M visits and 687K keywords. Unwinnable for a new directory in a month; realistically unwinnable at all without becoming a calculator.
- **"online calculator", "BMI calculator", "mortgage calculator", "loan calculator", "calorie calculator", "age calculator", "percentage calculator", "EMI calculator"** (bare forms) — each is owned #1–3 by a Tier A tool page that *is* the calculator. Intent mismatch: Google will not rank a directory above the tool.
- **"what is today" / "today's date"** — Inch Calculator #2; a date utility query, not a directory query.
- **"calculator.net" / "omni calculator" brand terms** (bare) — navigational; users want the site itself. Only the suffixed forms ("alternatives", "vs") are fair game.
- **"toolsped" / "rupayatools" brand terms** — near-zero volume; not worth a line of copy.

### Honest expectation for the 1-month goal

Page 1 in a month is plausible for: the Pakistan FAQ cluster (#1 above), "calculator.net alternatives", and several Tier E/F long tails — **if** the pages are indexed, the FAQs are real Q&A (not keyword lists), and the site is submitted/visible in Search Console. It is **not** plausible for "best calculator websites" head term against listme/miryori without backlinks, and it is not plausible for any bare tool keyword. The plan above orders work so the winnable queries ship first and the goal is judged on those, not on "calculator".
